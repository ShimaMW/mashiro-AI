# ましろ訪問看護ステーション・ましろ居宅介護支援事業所｜カンファレンス・担当者会議 AI議事録 — 仕様＆引き渡し手順書

ましろ訪問看護ステーション・ましろ居宅介護支援事業所（[https://mashiro-homecare.com/](https://mashiro-homecare.com/)）のブランドデザイン・実務フローに準拠し、介護ソフト「カイポケ」および訪問看護ソフト「iBow」の両対応、高速AI音声解析（Gemini 3.6 Flash）、長時間録音（Screen Wake Lock API）を備えた最新版の仕様・手順書です。

---

## 💡 主な機能と仕様まとめ

1. **出力先ソフトのワンタッチ切替（カイポケ用 ／ iBow用）**
   - **カイポケ用（居宅介護支援）**: 「全体要約」および「①検討した項目」「②検討内容」「③結論」「④残された課題」の5つの窓に分割出力。実地指導・監査に耐えうる検討プロセスと各専門職の発言を詳細に生成します。
   - **iBow用（訪問看護）**: iBowの単一入力ウインドウ仕様に合わせ、窓を分けず**1つのテキストエリアに全文を集約**。自事業所「ましろ」が提供するケア内容・役割・決定した具体的なToDoに強くフォーカスして生成します。
2. **会議名・開催区分の選択とAIプロンプト連動**
   - 最上部に「会議実施日」「利用者氏名」「会議名（サービス担当者会議／退院支援指導カンファレンス／退院共同指導カンファレンス／その他会議）」「実施の理由・開催区分（更新／新規／区分変更・状態変化／退院・退所時／サービス追加／定期・その他）」を配置。
   - 選択した会議名・開催区分がAI解析プロンプトの前提条件に組み込まれ、過去ログ保存・復元・一括コピー・CSV出力にも完全連動します。
3. **AI音声解析の分離・直接高速通信（Gemini 3.6 Flash 一本化）**
   - 従来の「音声データをBase64化してGAS経由で送る方式（50MB制限・6分タイムアウト）」を解消し、**Gemini Files API (Resumable Upload) ＋ Gemini 3.6 Flash (`gemini-3.6-flash`) への直接バイナリ転送**に対応。
   - 30分〜60分超の会議音声でも容量エラーを起こさず数十秒で高速解析します（1会議あたり約0.7〜1.2円の高コスパ）。
4. **ブラウザ長時間録音（Screen Wake Lock API ＋ 波形表示）＆ ボイスメモ両対応**
   - 直接録音時は `navigator.wakeLock` によりスマホ・タブレットの画面消灯（自動スリープ）を防止し、リアルタイムの音声波形と録音バックアップ保存ボタンを提供します。
5. **データベース（Googleスプレッドシート ＋ Supabase マルチ対応）**
   - 重い音声解析を分離したため、テキスト保存のみのGoogleスプレッドシートは **0.5秒以下** で応答し、フロントエンドキャッシュにより履歴一覧は即時表示されます。

## 🔄 知人事業所（ましろ様）への引き渡し・初期設定手順

### ステップ1：Google AI Studio で Gemini APIキーを取得（約1分）
1. [Google AI Studio (APIキー発行画面)](https://aistudio.google.com/apikey) にアクセスし、Googleアカウントでログインします。
2. **「Create API key」**（新しいプロジェクトでAPIキーを作成）をクリックし、`AIzaSy...` で始まるキーをコピーします。

### ステップ2：ましろ様用のGoogleスプレッドシート＆GASの作成（約2〜3分）
1. ましろ様のGoogleアカウントで **新規スプレッドシート** を作成します（列見出しは初回保存時に自動生成されます）。
2. 上部メニューの **「拡張機能」 → 「Apps Script」** を開きます。
3. プロジェクト内の `Code.gs` の内容をすべて貼り付けて保存（💾）します。
4. 右上の **「デプロイ」 → 「新しいデプロイ」** を選択します。
   - 種類: **ウェブアプリ**
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
5. 発行された **「ウェブアプリのURL (`https://script.google.com/macros/s/.../exec`)」** をコピーします。

## 🚀 GitHub ＆ Vercel による無料Web公開手順（おすすめ）

スタッフがスマホやタブレット、各PCからURL（`https://mashiro-minutes.vercel.app` 等）を開くだけで使えるようにする手順です。

### 1. GitHub への登録とプッシュ（初回）

1. [GitHub](https://github.com/) にログインし、右上の「＋」→ **「New repository」** をクリックします。
2. リポジトリ名（例: `mashiro-ai-minutes`）を入力し、公開設定を **「Private（非公開・推奨）」** にして「Create repository」をクリックします。
3. パソコンのターミナル（PowerShell等）で以下のコマンドを実行してコードをプッシュします：

```powershell
# 変更ファイルをすべてステージング
git add .

# コミットを作成
git commit -m "feat: ましろ訪問看護・居宅介護支援 AI議事録システム完成版"

# 新しいGitHubリポジトリをリモート先に設定（YOUR_ACCOUNT / REPO_NAME はご自身のものに置換）
git remote set-url origin https://github.com/YOUR_ACCOUNT/mashiro-ai-minutes.git

# GitHubへプッシュ
git branch -M main
git push -u origin main
```

---

### 2. Vercel と連携してWeb公開する（初回・約2分）

1. [Vercel](https://vercel.com/) にアクセスし、**「Continue with GitHub」** でログインします。
2. ダッシュボードの **「Add New...」 → 「Project」** を選択します。
3. 先ほど作成した GitHub リポジトリ（`mashiro-ai-minutes`）の横にある **「Import」** をクリックします。
4. **Environment Variables（環境変数）の設定（★最重要・セキュリティ対策）**:
   * 画面内の「Environment Variables」を開きます。
   * **Key**: `GEMINI_API_KEY`
   * **Value**: ステップ1で取得したGemini APIキー（`AIzaSy...`）
   * 「Add」をクリックして追加します。
   > ※これにより、フロントエンドにAPIキーを露出させることなく、サーバーレス関数（`/api/gemini.js`）経由で安全に高速AI解析が実行されます。
5. **「Deploy」** をクリックします。
6. 数十秒でデプロイが完了し、`https://mashiro-ai-minutes.vercel.app` のような専用URLが発行されます！

### 3. 今後の修正・更新時のプッシュ方法（日常の作業）

コードを変更（文字の修正、レイアウト調整など）した後は、以下の **3行のコマンド** を打つだけで、Vercelが自動検知して数十秒で本番サイトが更新されます。

```powershell
# 1. 変更したファイルをすべて追加
git add .

# 2. 更新内容のメッセージを付けてコミット
git commit -m "デザイン微調整とプロンプト改善"

# 3. GitHubへプッシュ（Vercelが自動で本番サイトを更新します）
git push origin main
```
